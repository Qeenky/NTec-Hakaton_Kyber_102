# Готовый APK

`ntec-inspector.apk` — release-сборка Android arm64 из `mobile/`.

## Установка

1. Разрешите установку из неизвестных источников.
2. Установите APK.
3. В приложении: «Настройки подключения» → адрес сервера
   `http://<IP-сервера>:8000` (телефон и сервер в одной сети).
4. QR: `ar_board/qr/PUMP-001.png` или `PUMP-002.png`.

## Демо

1. QR `PUMP-001` → чистый планшет `ar_board/out_real/board_A3.png` → «норма».
2. QR `PUMP-002` → дефектный планшет `ar_board/out_defect/board_A3.png` →
   коррозия/окисление, AI-проверка, сохранение осмотра.

Планшеты также открываются с экрана: `ar_board/screen/board_switch.html`
(клавиши `1` / `2`).
